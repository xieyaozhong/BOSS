一份樂譜，
變成一個樂團。

把旋律、和聲、低音、弦樂鋪底與對位拆成不同聲部，每一軌都能選自己的樂器音色、音量、靜音與獨奏。播放時所有軌道共用同一個節拍時間軸，因此可以真正同步合奏。

NO API CREDITSoundFont + Web Audio優先使用公開 MusyngKite SoundFont 載入鋼琴、弦樂、木管、銅管、吉他等真實取樣音色；若外部音色載入失敗，會自動改用瀏覽器內建合成器，不讓整個編曲器失去聲音。

編曲設定

先選音樂方向，再決定樂團編制。生成後可以逐軌換樂器、調音量、Mute / Solo，再重新播放。

開源核心

abcjs ↗ 負責多聲部五線譜與 MIDI；soundfont-player ↗ 搭配 MusyngKite SoundFont 負責各樂器取樣播放。兩者都在瀏覽器端運作，不需要 OpenAI API 或其他生成式 AI 額度。
